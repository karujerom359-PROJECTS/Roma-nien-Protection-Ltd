ROMA-NIEN PROTECTION LIMITED WEBSITE

HTML pages:
- index.html       Home page
- about.html       About the company
- services.html    Security services
- values.html      Mission, vision and core values
- contact.html     Contact details and enquiry form

Supporting files:
- style.css        Shared website styling
- script.js        Mobile navigation, reveal effects, year and email enquiry handler

HOW TO USE
1. Extract the ZIP file.
2. Keep all five HTML files, style.css and script.js in the same folder.
3. Open index.html in a browser to preview the website.
4. In script.js, replace YOUR-COMPANY-EMAIL@example.com with the real company email.
5. In contact.html, replace the phone, email and office address placeholders.
6. Upload all files together to your web hosting account.

NOTES
- Images are loaded from Unsplash and require an internet connection.
- The enquiry form opens the visitor's email application; it does not store or send messages by itself.
- Confirm all services, licences, registrations and company claims before publishing.
